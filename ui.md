# TezSend UI Prompts (Secure Banking Theme)

Use these prompts in your preferred AI UI generator (e.g., v0.dev, Midjourney for mockups, or an AI coding assistant) to generate the frontend aesthetics.

## Global Theme & Aesthetic Rules
**Theme Prompt:** 
> "Create a global design system for a modern, secure fintech web application called 'TezSend'. The aesthetic should inspire extreme trust and premium quality. Use a color palette featuring deep navy blues (like `#0A192F`), rich emerald greens for success states, and stark whites for contrast. Typography must use a modern sans-serif like 'Inter' or 'SF Pro'. Use subtle glassmorphism (translucent panels with background blur) to make it feel state-of-the-art. Include micro-animations on hover states. The layout must be fully responsive, prioritizing a mobile-first 'app-like' experience."

---

## 1. Authentication Page (Login/Register)
**Page Prompt:**
> "Design a secure login and registration page for a banking app. The screen should be split: one side featuring a subtle, abstract 3D secure vault or shield graphic with a dark gradient background, and the other side featuring a clean, glassmorphic login card. The card needs input fields for Email and Password, and a prominent, highly polished 'Login' button. Below it, include a 'Sign in with Google' button with the Google logo. Add a small lock icon near the password field and text saying '256-bit Secure Encrypted Connection' at the bottom to build trust."

---

## 2. Main Dashboard
**Page Prompt:**
> "Design the main dashboard for a fintech app. The top header should welcome the user by name with a circular avatar profile picture. Below the header, design a 'Total Balance' or 'Quick Actions' premium card featuring a subtle metallic or dark gradient texture. The layout should have a grid of quick-action buttons with sleek icons: 'Send Money', 'Add Card', and 'View Beneficiaries'. Below this, design a 'Recent Transactions' list. Each transaction row should show a bank logo or initial, the beneficiary's name, the date, and the amount in bold (green for received, white/black for sent). The design must feel organized, spacious, and extremely professional."

---

## 3. Add Beneficiary / Add Card Page
**Page Prompt:**
> "Design a secure data-entry form page for adding a new bank beneficiary or debit card. The page should have a 'Back' button in the top left. Center a clean, well-padded form card on the screen. For the beneficiary form, include floating-label input fields for 'Bank Name', 'Account Number', 'IFSC Code', and 'UPI ID'. Use a green checkmark icon that appears when a field is filled out correctly. The submit button should be a wide, solid primary color button saying 'Securely Save Beneficiary'. Include a subtle shield icon and text below the button stating 'Your data is encrypted and never shared'."

---

## 4. Initiate Transaction (Send Money)
**Page Prompt:**
> "Design a 'Send Money' flow screen for a banking app. The top of the screen should show the selected beneficiary's details (Name and Bank Account ending in 4 digits) inside a neat, elevated card. Below it, design a large, prominent keypad or input area for the user to type the 'Amount to Send'. The typography for the amount should be massive and clear (e.g., ₹5,000). Below the amount, show a small, subtle text breaking down the '2% Convenience Fee' and the 'Total Deducted'. The main action button at the bottom should be a vibrant, trusting color saying 'Proceed to Pay ₹5,100'. It should look like a highly polished, modern mobile wallet interface."
